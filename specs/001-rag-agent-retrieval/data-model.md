# Data Model: RAG Agent Service

## Entities

### Agent Query

Represents a user's input to the RAG agent service.

**Attributes**:

-   `query_text` (string): The natural language question or prompt from the user.
-   `context_snippet` (string, optional): An optional text snippet provided by the user to limit the agent's response context.

### Retrieval Tool

Represents the interface of the tool that the AI agent will use to retrieve relevant information from Qdrant.

**Attributes**:

-   `tool_name` (string): e.g., "qdrant_retriever"
-   `tool_description` (string): A description for the AI agent on when and how to use this tool (e.g., "Retrieves relevant document chunks from the Qdrant vector database based on a natural language query.").
-   `parameters` (dict): Defines the input parameters for the tool (e.g., `query: str`, `top_k: int`).

### Agent Response

Represents the AI agent's answer to a user's query.

**Attributes**:

-   `response_text` (string): The natural language answer generated by the AI agent.
-   `source_references` (list of strings, optional): URLs or identifiers of the documents from which information was retrieved to form the answer.
-   `used_context` (string, optional): The specific context (retrieved chunks or provided snippet) that the agent used to formulate the answer.

### Retrieved Chunk

(This entity is inherited and used from Spec 1 and Spec 2, but its role in the agent service is as an input to the agent's reasoning process.)

**Attributes**: (As defined in Data Model: RAG Retrieval Pipeline)

-   `chunk_text` (string)
-   `source_url` (string)
-   `page_title` (string)
-   `chunk_index` (integer)
-   `content_hash` (string)
-   `embedding` (list of floats)
-   `score` (float)

## Data Flow for FastAPI Endpoint

**Request Body Example (`/chat` endpoint)**:

```json
{
  "query_text": "What are the benefits of using FastAPI?",
  "context_snippet": "FastAPI is a modern, fast (high-performance) web framework for building APIs with Python 3.7+ based on standard Python type hints."
}
```

**Response Body Example (`/chat` endpoint)**:

```json
{
  "response_text": "Based on the provided context, FastAPI is a modern, fast (high-performance) web framework for building APIs with Python 3.7+ based on standard Python type hints.",
  "source_references": ["https://fastapi.tiangolo.com/"],
  "used_context": "FastAPI is a modern, fast (high-performance) web framework for building APIs with Python 3.7+ based on standard Python type hints."
}
```
