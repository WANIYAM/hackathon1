# Quickstart

This documentation feature will be structured as a new module in the Docusaurus sidebar. To define the module's appearance in the sidebar, a `_category_.json` file will be created in the module's directory (`ros2-docs/docs/module4`).

## `_category_.json`

```json
{
  "label": "Module 4: Vision-Language-Action",
  "position": 4,
  "link": {
    "type": "generated-index",
    "description": "Integrate language models with robotic perception and action for autonomous humanoid behavior."
  }
}
```
