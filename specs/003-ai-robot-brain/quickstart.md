# Quickstart

This documentation feature will be structured as a new module in the Docusaurus sidebar. To define the module's appearance in the sidebar, a `_category_.json` file will be created in the module's directory (`ros2-docs/docs/module3`).

## `_category_.json`

```json
{
  "label": "Module 3: The AI-Robot Brain",
  "position": 3,
  "link": {
    "type": "generated-index",
    "description": "Implement advanced perception, navigation, and training for humanoid robots using NVIDIA Isaac."
  }
}
```
