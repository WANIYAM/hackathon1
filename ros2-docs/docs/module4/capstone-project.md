# Capstone Project: The Autonomous Humanoid

This chapter guides you through the process of building an end-to-end system that combines voice input, navigation, vision, and manipulation in a simulated environment.

## Project Goal

The goal of the capstone project is to build a simulated humanoid robot that can understand natural language commands and perform a complex task, such as finding an object in another room and bringing it back.

## Key Components

- Voice Command Interface
- Cognitive Planning Module
- Navigation and Path Planning
- Vision and Object Recognition
- Manipulation and Grasping
