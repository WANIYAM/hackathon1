# Cognitive Planning with LLMs

This chapter explains how to translate natural language goals into structured ROS 2 action sequences using Large Language Models (LLMs).

## Key Concepts

- Large Language Models (LLMs)
- Prompt Engineering
- Task Planning
- ROS 2 Services

## Example

We will build a system that takes a high-level goal like "go to the kitchen and pick up the apple" and breaks it down into a sequence of ROS 2 actions.
