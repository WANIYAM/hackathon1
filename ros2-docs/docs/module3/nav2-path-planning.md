# Path Planning with Nav2

This chapter focuses on Path Planning with Nav2 for bipedal humanoid movement and navigation strategies in a simulated environment, including dynamic obstacle avoidance.

## Key Concepts

-   ROS 2 Navigation Stack (Nav2)
-   Global and Local Planners
-   Dynamic Obstacle Avoidance
-   Humanoid Locomotion

## Example

We will configure Nav2 to work with a humanoid robot in Isaac Sim, enabling it to navigate through an environment with moving obstacles and reach a specified goal.
