# Hardware-Accelerated VSLAM with Isaac ROS

This chapter focuses on Hardware-Accelerated VSLAM (Visual Simultaneous Localization and Mapping) with Isaac ROS for real-time humanoid perception.

## Key Concepts

-   Visual SLAM
-   Isaac ROS
-   Real-time Perception
-   Pose Estimation
-   Map Reconstruction
-   Stereo Cameras

## Example

We will implement a VSLAM pipeline using Isaac ROS that takes input from stereo cameras in Isaac Sim and produces a real-time pose estimate and a 3D map of the environment.
